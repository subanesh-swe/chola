# ChQL Corpus

This directory contains the shared test corpus for the Chola Query Language (ChQL) — see [`local/plans/CHQL.md`](../../local/plans/CHQL.md) for the full grammar and AST specification. Each file is a single test case named `NNN_short_name.json` with either a `{ "input", "ast" }` pair (success) or a `{ "input", "error" }` pair (expected parse failure). Both the Rust parser (`cargo test -p chola-controller --test chql_corpus`) and the TypeScript parser (`pnpm vitest run chql.corpus`) iterate every file in this directory and assert that parsing `input` produces the matching `ast` (or an error with the given `message` and `position`). An empty input (`""`) produces `{ "ast": null }`. The 40 cases span atoms (001-010), combinators (011-022), field types (023-030), and error cases (031-040).
